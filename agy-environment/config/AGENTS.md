# Android GUI Agent 通用执行与验收准则

## 一、核心原则：输入文字 ≠ 任务完成，必须显式提交并核验结果
- **输入与提交分离**：任何文本输入工具（input_text、replace_text、paste_text）仅仅是向输入框填入文字，绝对不会自动向服务器提交或发起请求！
- **严禁在未提交时宣称完成**：任何包含提交性质的任务（如“搜索 X”、“发送消息”、“发表评论”、“登录/提交”），输入文字仅仅是前置准备，必须紧接着显式调用 tap_element 点击界面上的“搜索”、“发送”、“确定”等提交按钮。
- **未点击提交按钮的任务 100% 未完成**：凡是未曾成功点击提交按钮的搜索或发送任务，严禁向用户反馈已完成！

## 二、搜索类任务完成准则（Search Completion）
当用户要求“搜索 X”时，必须严格按以下阶段执行到底：
1. **阶段 1（进入搜索界面）**：定位并点击搜索图标/搜索框，进入搜索界面；
2. **阶段 2（输入搜索词）**：使用 replace_text 将搜索词 X 填入搜索输入框；
3. **阶段 3（显式提交搜索，关键步骤）**：
   - 输入词条后，下方自动弹出的列表仅为输入建议/联想词（Suggestions/AutoComplete），绝不是正式搜索结果；
   - 此时输入框仍处于编辑态（focused: true），且界面右侧或上方必然存在“搜索”按钮（例如 Button text='搜索' 或放大镜图标）；
   - 必须立即调用 tap_element 点击该“搜索”按钮（或点击特定候选条目）以真正发起搜索！
4. **阶段 4（主动观察并核验正式结果）**：
   - 提交搜索后，必须重新调用 observe_screen；
   - 核验界面已脱离输入建议态，正式搜索结果已渲染上屏（例如出现结果分类 Tab，以及具体的图文笔记、卡片瀑布流或商品列表）；
   - 只有在观察确认正式搜索结果已呈现在屏幕上之后，方可向用户汇报任务完成。

## 三、应用启动与导航类任务准则（Navigation Completion）
- 当用户要求“打开某应用”：必须核验目标应用已在前台并进入主功能界面（若有开屏广告或权限弹窗，需协助点击跳过/允许，或明确提示）。
- 当用户要求“进入某页面/设置”：必须核验目标页面的标志性标题或控件已在屏幕呈现。

## 四、消息发送与表单类任务准则（Action Submission）
- 当用户要求“发送消息”：输入文本后，必须点击“发送”按钮；提交后调用 observe_screen 核验消息已出现在消息气泡列表中且输入框已清空，方可认为发送成功。

## 五、虚拟屏幕技术规范（严防画中画与键盘抢占）
- **严禁使用 `settings put global overlay_display_devices`**：该命令底层是 AOSP OverlayDisplayWindow，会在物理主屏幕 Display 0 强制贴出半透明画中画浮窗并抢夺输入法键盘焦点，严重干扰用户！全系统绝对禁止使用！
- **离屏纯内存 VirtualDisplay（`virtual_display`）**：必须使用通过 `headless_server.dex` / `virtual_display` 提供的离屏纯内存渲染。保证零浮窗、零画中画、零软键盘抢占。
- 任务结束后如无长期后台需求，必须显式销毁虚拟屏幕（`virtual_display destroy`）。

## 六、拟人化抗风控触控规范
- **严禁瞬间零延迟点击（Anti-0ms Tap）**：严禁连续无延迟触发 DOWN 与 UP。
- **拟人化替代方案**：使用带有自然接触时长（50ms~120ms）与微位移（1~2px）的手势模拟人手指腹按压：`input swipe <x> <y> <x+1> <y+1> 75`（虚拟屏使用 `input -d <displayId> swipe ...` 或 `virtual_display tap <x> <y>`）。
- **滑动与滚动仿真**：列表滑动时长控制在 300ms~650ms，带有自然阻尼与像素偏差。

## 七、安全红线守护（严禁擅自重启/关机/破坏性系统操作）
- **绝不自行重启**：Agent 严禁在日常诊断、修复或实验中自行执行 `reboot`、`shutdown`、`poweroff`、`svc power reboot`、`setprop ctl.restart` 等危险命令。
- **必要重启的处理准则**：若系统级修改必须依赖系统重启方可生效，Agent 必须停下来向用户输出完整的修复总结报告，并明确告知“所有配置已修改完毕，需手动重启手机生效”，等待用户确认，绝不可擅作主张。
